Возможности

Всё нужное. Ничего лишнего.

Каждый модуль движка — маленький, автономный класс с одной ответственностью. Никакой «магии»: код читается от index.php до последнего шаблона.

⚡️

Front Controller + Route

Единая точка входа index.php. Собственный маршрутизатор нормализует URI (REDIRECT_URL / PATH_INFO / REQUEST_URI) и отдаёт служебные URL — sitemap, robots, статику — до основной обработки.

🧲

DI-контейнер

Лёгкий Container с supports singleton() и глобальным доступом. Порядок инициализации ядра зафиксирован и документирован прямо в bootstrap.php.

🗄️

Database через PDO

Тонкий слой DataBase + DbQuery над нативным PDO/MySQL. Никакого ORM-оверхеда — только предсказуемые запросы и lazy-соединение.

🔑

Аккаунты и Redis-сессии

Модуль AccountManagementSystem: пользователи, права, безопасные сессии с хранением в Redis (или файлах) и защитой от session fixation.

📝

Logger с ротацией

Собственный классифицированный логгер: отдельные каналы для публичной части и админки, уровни, контекст, запись в core/log/.

🎨

Template Engine

Простые HTML-шаблоны с layout, partials и подстановкой блоков. Отделение разметки от логики без тяжёлых шаблонизаторов.

🕸️

Schema.org JSON-LD

Модуль Schema автоматически генерирует семантическую микроразметку страниц — SEO «из коробки», без плагинов.

🛡️

Безопасность на уровне web-server

Поставляемый .htaccess: HTTPS-редиректы, защита core/, vendor/, admin/, deny для env-файлов и логов, точечная маршрутизация.

🛠️

Админ-панель в комплекте

Отдельный front controller admin/admin.php со своим роутингом, логгером, контроллерами (Dashboard, PageSettings) и шаблонами — из коробки.

Архитектура

Как живёт один запрос

Прозрачный конвейер без скрытых слоёв — вы видите весь путь от URI до HTML.

1
bootstrap.phpАвтозагрузка (Composer или fallback spl.php), базовые пути Route/File, создание DI-контейнера.
2
Регистрация синглтоновConfig (env-точка истины) → TimeDate → Logger → Database → Session — порядок строго детерминирован.
3
Url::getRequestUri()Нормализация URI в единой точке истины, отсечение query-string, защита прямого доступа к front controller.
4
Route::getServiceHandler()Служебные адреса (sitemap.xml, robots.txt, статика) обрабатываются раньше страниц.
5
PageController + TemplateСтраницы из БД рендерятся через layout-шаблоны; Schema добавляет JSON-LD.
6
set_exception_handlerГлобальный перехват сбоев: запись в Logger и отдача 500-fallback — белые экраны невозможны.
// index.php — весь вход приложения
require_once __DIR__ . "/core/bootstrap.php";

$di     = Container::getGlobal();
$logger = $di->get(Logger::class);

$path = Url::getRequestUri();       // нормализация
$svc  = Route::getServiceHandler('/' . $path);

if ($svc !== null) {                // sitemap, robots…
    require_once $svc;
    exit;
}

// …страница → PageController → Template → HTML

Философия

Почему самостоятельный движок?

Большие фреймворки решают все задачи сразу. VampqweEngine решает задачи конкретного проекта — и ничего больше.

✓

Полный контрольКаждая строка написана автором — никаких скрытых vendor-слоёв между вами и поведением приложения.

✓

Нулевая инерцияНет миграций версий, deprecated API и ломающих обновлений чужого фреймворка.

✓

ЧитаемостьЯдро ~15 классов читается за вечер. Новый разработчик входит в проект без документации на 300 страниц.

✓

ПроизводительностьНикакого посредничества: запрос идёт напрямую через тонкий слой PDO, шаблон рендерится без рекомпиляции.

✓

ПереносимостьОдин bootstrap, один config.env — проект разворачивается на любом LAMP/LEMP за минуты.

✓

Fallback-автозагрузкаДаже без Composer движок стартует: встроенный spl.php регистрирует классы ядра.

Быстрый старт

Запуск за три шага

От клонирования до первого рендера — меньше минуты.

Получить движок

git clone https://github.com/Vampqwe/VampqweEngine.git cd VampqweEngine

Или как пакет: composer create-project vampqwe/engine site

Настроить конфигурацию

cp core/config.env.example core/config.env

Укажите MySQL, Redis, домен и режим отладки — Config прочитает файл на старте.

Зависимости и запуск

composer install --no-dev php -S localhost:8000 index.php

Для продакшена — Apache c готовым .htaccess: rewrite и защита папок уже настроены.
